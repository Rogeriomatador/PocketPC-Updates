# PocketPC — downloads oficiais

**Criado por Rogério Martins ([@Rogeriomatador](https://github.com/Rogeriomatador)).**

## Baixar no Android

➡️ **[Abrir as versões do PocketPC](https://github.com/Rogeriomatador/PocketPC-Updates/releases)**

No celular, abra a primeira versão, expanda **Assets** e toque no arquivo que termina
em `.apk`.

O Android ou o Google Play Protect pode verificar o arquivo e pedir confirmação antes
da instalação. Essa etapa pertence ao sistema Android e pode demorar em conexões lentas.

## Sobre este repositório

Este repositório público contém somente o feed OTA e os APKs assinados do PocketPC.
O arquivo `latest.json` é consumido automaticamente pelo atualizador do aplicativo.

As versões atuais são **Home Test / desenvolvimento**. Uma compilação publicada não
significa que Wine, Box64, DXVK, Roblox ou todo o runtime de PC tenha passado em teste
físico.
